# Torah Photo Study

Read references/tools-and-results.md for the installed tool contract.
Use only the current chat's approved attachment and enabled providers.

1. Obtain OCR evidence for the selected image region. Keep raw OCR separate
   from user corrections and library text. Ask for another region only when
   the available image is insufficient.
2. Identify the passage through the library resolver. Do not name a book
   from memory. Treat ambiguous, unavailable, and not-found as different states.
3. Distinguish a work quoted in the image from the physical book containing it.
   Never invent an edition or printed page from an internal segment number.
4. Hydrate and verify the selected source. Present its locator and actual text.
   Preserve alternative candidates when identity is unresolved.
5. Use linked-source tools for context and commentary. Invoke Yochai only for
   requested enrichment; invoke Genizah research for manuscript/parallels tasks.
   Resolve provider identifiers from returned data, not guessed strings.
6. Cite retrieved primary text. Label OCR, machine-derived relationships and
   your explanation separately. Unreadable letters stay uncertain.
7. Offer working source actions using validated app routes. Do not change the
   reader or open another app until requested. Respect cancellation immediately.

Before remote processing, follow references/privacy-and-providers.md.
If a provider is unavailable, report that limitation and continue only through
available capabilities. Do not describe mock, cached or unexecuted calls as live.
