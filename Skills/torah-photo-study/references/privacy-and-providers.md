# Privacy and Providers Policy

1. **Local-First Processing**: When operating under `local_only` or `prefer_local` policy, image data and OCR transcription remain on-device. No network requests are made.
2. **Explicit Consent**: Remote OCR or cloud enrichment (such as HebVL or remote LLM vision) requires explicit user approval.
3. **No Secret Leakage**: API keys, credentials, and sensitive tokens are strictly excluded from tool results, prompts, logs, and exports.
