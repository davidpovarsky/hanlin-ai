# Hanlin 147501 presentation and scroll-lifetime repair

## Baseline and diagnosis

The owner's observed TestFlight build is **0.7.3 (147501)**, application source
`45612d73532f1ad77c312353c66de81631cb67c3`. This change starts from its documentation
follow-up `a2cede2099ba100d16f91d23126782327628de6d`.

The supplied V17 demonstrations expose concrete integration differences: an
always-visible 112-point JSON approval viewport; hidden headers for genuine
singleton rounds; generic activity names; a generated UUID appended to visible
model labels; and no claim-level citation path for Chat Completions providers.
The current catalog also lacked several approval/activity translations.

The supplied crash aborts through CALayer bounds, UIScrollView bounds/offset and
SwiftUI HostingScrollView attachment. It has no exception reason or causal app
frame identifying a unique view. The fixes below address demonstrated lifecycle
and finite-layout risks; the report alone cannot prove the exact original trigger.
Private screenshots and the original crash report are not committed.

## Changes

- Keep real round ownership and the original activity disclosure. Show genuine
  singleton headers, aligned reasoning/tool rows, specific location/weather/route/
  calendar titles and actual source icons/counts. Empty completed subsecond
  reasoning no longer adds a meaningless zero-second row.
- Present an approval's readable exact scope in the compact V17 card. Keep the
  original request and tool identity in manual details. Complex values must be
  reviewed before Allow; no permission, invocation or request identity is changed.
- Use one finite vertical details viewport and remove nested horizontal source
  scrolling. Invalidate pending positioning when the real viewport, insets or window
  change, reject outgoing-conversation callbacks, stage incoming bindings and scope
  the original reader/bottom identity to its conversation.
- Recognize explicit citations only against sources actually returned to the model.
  Add exact source URLs to existing legacy tool results and prompt for a source link
  after sentence punctuation. Persist hashed UTF-16 anchors, preserve ordered-part
  scope, retain ordinary links and ignore unmapped numeric references. Keep one
  all-sources footer and original native Markdown selection/navigation.
- Display readable model labels without changing routing identifiers or old
  history. Fix Unicode title search indexing. Localize new activity/approval,
  draft/image/date and interruption/error labels, including compiled-app checks.
- Preserve up to 32 distinct actually-returned URL aliases on the existing source
  record when canonical deduplication folds a page and its section links together.
  Unknown fragments remain ordinary links; original source count and primary
  destination are unchanged, and older saved records still decode. Inline chips
  and scoped sheets also retain the source reader's actual HTTPS favicon, including
  CDN paths, through canonical/alias projection; invalid icons use the existing
  default and cannot become citation destinations.
- Reuse the shared Apple location service instead of the separate fixed-delay
  authorization path. Preserve valid coordinates on address lookup failure and
  original cancellation. Emit the existing map payload on success; location and
  weather failures/cancellations now have truthful structured outcomes. Weather
  guidance requires coordinates and exposes map tools only when enabled.
- Match the demonstration's follow-latest control with a neutral semibold arrow,
  system background and soft shadow, preserving the original 36-point control,
  placement, scrolling action and transition.
