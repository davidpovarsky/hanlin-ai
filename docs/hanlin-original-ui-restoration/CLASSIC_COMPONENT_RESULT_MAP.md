# Classic Component Result Map

Every output produced by the `SwiftAISDK.streamText` agent engine (`HanlinAISDKAgentEngine`), `HanlinAISDKToolAdapter`, and `APIManager` maps deterministically through `ClassicChatAgentProjection` into `ChatMessages` SwiftData fields and renders inside the original `ChatBubbleView` in `AI_HLY/Views/Components/ChatViewComponents.swift`.

---

## 1. End-to-End Projection Matrix

| SDK / Tool / Provider Output | `StreamData` Transport Field | `ClassicChatAgentProjection` Handler | Persisted `ChatMessages` Field(s) | Original `ChatBubbleView` Section | Interactive User Actions Preserved |
|---|---|---|---|---|---|
| Assistant streaming text (`HanlinAISDKStreamEvent.textDelta`) | `StreamData.content` | `ClassicChatAgentProjection.stripRawThinkTags` | `assistantMessage.text` | `textSection()` (`Markdown` / `LaTeX` math mode) | Copy (`square.on.square`), Text Selection (`TextSelectionView`), TTS (`waveform`), Translate (`translate`), Math Mode (`x.squareroot`), Save to Knowledge (`backpack`), Retry, Delete |
| Sanitized reasoning / progress summary (`HanlinAISDKStreamEvent.reasoningDelta`, `.stepStarted`) | `StreamData.reasoning` & `StreamData.agentEvent` | `ProgressSummarySanitizer.sanitizeProviderReasoningSummary` | `assistantMessage.reasoning`, `assistantMessage.reasoningTime`, `assistantMessage.agentRunData` | `reasoningView()` (`ToggleButton(title: "reasoning_chain")`) | Expand/collapse reasoning chain (`hanlin-reasoning-toggle`), text selection; raw `<think>` / CoT blocked |
| Tool execution start & output (`HanlinAISDKStreamEvent.toolCallStarted`, `.toolCallFinished`, `.toolOutputDenied`, `.toolApprovalRequest`) | `StreamData.toolContent`, `StreamData.toolName`, `StreamData.agentEvent` | `ClassicChatAgentProjection.applyAgentEvent` & `finalizeTurn` | `assistantMessage.toolContent`, `assistantMessage.toolName`, `assistantMessage.agentRunData` | `toolContentView()` (`ToggleButton(title: "tooluse_content")`) | Expand/collapse tool usage details (`hanlin-tool-content-toggle`), text selection |
| Online search & web page reading (`search_online`, `read_web_page`) | `StreamData.searchBubbleText`, `StreamData.searchBubbleResources`, `StreamData.searchResources`, `StreamData.searchEngine` | `ClassicChatAgentProjection.upsertSearchMessage` & `filterValidResources` | Dedicated `ChatMessages(role: "search")` row + `assistantMessage.resources` | `searchMessageView()` (`信息内容` capsule) + `resourcesView()` (`参考资料` section) | Tap `book` icon to open `ResourcesSheetView` (`hanlin-search-book-button`), tap citation row to open Safari, tap `xmark.circle` to delete search row (`hanlin-search-delete-button`) |
| Provider-native source citation (`HanlinAISDKStreamEvent.source`) | `StreamData.sourceId`, `StreamData.sourceUrl`, `StreamData.sourceTitle` | `ClassicChatAgentProjection.appendProviderSource` | `assistantMessage.resources` + `ChatMessages(role: "search")` | `searchMessageView()` & `resourcesView()` | Deduplicated HTTP/HTTPS citation links; `search.local` rejected |
| Provider-native generated/returned file (`HanlinAISDKStreamEvent.file`) | `StreamData.fileMimeType`, `StreamData.fileData` | `ClassicChatAgentProjection.appendProviderFile` | `assistantMessage.imagesArray` (for `image/*`) or `assistantMessage.uploadDocument` | `imagesSection()` or `uploadDocumentsSection()` | Full-screen `ImageViewer` zoom/save/share or `QuickLook` document preview |
| Python / JS / TS / Shell code execution (`execute_local_python_code`, `execute_python_code`, `execute_javascript_code`, `execute_typescript_code`, `execute_shell_command`) | `StreamData.codeBlock` (`CodeBlock`) & `StreamData.toolContent` | Appended to `assistantMessage.codeBlocks` + `toolContent` | `assistantMessage.codeBlocks` (`[CodeBlock]`) | `codeBubble()` (`CodeBlockRow`: `源代码` + `运行结果`) | `查看代码` (`CodeDetailSheet`), `运行代码` (`PistonRunner`), copy code, inspect stdout/stderr |
| Static HTML snippet (`create_html_card` / HTML content) | `StreamData.htmlContent` | Assigned to `assistantMessage.htmlContent` | `assistantMessage.htmlContent` | `htmlBubble()` (`WebContentPreviewView`) | Interactive WebKit preview, `全屏查看` (`WebFullScreenSheet`), `复制代码` |
| Map coordinates & routes (`search_map_locations`, `plan_route`) | `StreamData.locations`, `StreamData.routes` | Assigned to `assistantMessage.locations` / `routes` | `assistantMessage.locations`, `assistantMessage.routes` | `mapBubble()` (`MultiLocationMapView`) | Interactive MapKit annotations, route polylines, open in Apple Maps |
| Canvas document (`create_canvas`, `update_canvas`) | `StreamData.canvas`, `StreamData.showCanvas` | Assigned to `assistantMessage.canvas` & `chatRecord.canvas` | `assistantMessage.canvas`, `assistantMessage.showCanvas` | `canvasBubble()` (`CanvasCardView`) + floating `画布` button in `ChatViewBottom` | Open `CanvasEditorSheet` to edit/copy/export canvas content |
| Calendar & Reminder events (`create_calendar_event`, `create_reminder`) | `StreamData.events` | Assigned to `assistantMessage.events` | `assistantMessage.events` | `eventBubble()` (`EventCardView`) | EventKit integration & status display |
| HealthKit records (`query_health_data`, `log_health_data`) | `StreamData.healthCards` | Assigned to `assistantMessage.healthCards` | `assistantMessage.healthCards` | `healthBubble()` (`HealthCardView`) | Health metric visualization card |
| Knowledge cards (`save_knowledge_card`, `search_knowledge`) | `StreamData.knowledgeCard` | Assigned to `assistantMessage.knowledgeCard` | `assistantMessage.knowledgeCard` | `knowledgeBubble()` (`KnowledgeCardView`) | `写入知识背包` / `查看知识文档` (`KnowledgeWritingSheet`) |
| Interactive Mini-App / NativeScript / Svelte surface (`render_native_ui`, `create_web_view`, `launch_mini_app`) | `StreamData.nativeUIBlock` (`NativeUIBlock`) | Appended to `assistantMessage.nativeUIBlocks` | `assistantMessage.nativeUIBlocks` | `nativeUIBlockSection()` -> `ChatEmbeddedResultHost` -> `NativeUIRenderer` | Interactive inline card with `.hlBlue` border, `展开` sheet, `全屏` presentation, `代码` source sheet, `复制` |
| Run failure / HTTP / provider error (`HanlinAISDKStreamEvent.error`) | `StreamData.errorMessage` | Creates `ChatMessages(role: "error")` | `ChatMessages(role: "error", text: errorDescription)` | `errorMessageView()` | `arrow.clockwise.circle` (`onRetry` -> `ClassicChatAgentProjection.cleanupTurnForRetry`), `xmark.circle` (`onDelete`) |
