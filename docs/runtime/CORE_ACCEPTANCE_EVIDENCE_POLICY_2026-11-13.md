This contract applies only to the56 individual Core obligations retained in
[`evidence/CORE_56_COVERAGE_2026-11-13.json`](evidence/CORE_56_COVERAGE_2026-11-13.json).
It implements the owner's impact-aware evidence policy without removing cases,
changing assertions or replacing the broader Runtime Tooling, UI or physical

selected unit cases executed in run43267408632.

Core coverage may aggregate authentic per-case `EXECUTED_PASS` and
`REUSED_VERIFIED_PASS`. A reuse candidate is **not** an accepted pass. It requires:

- Original actual passed leaf node, legitimate completed test driver, authenticated
  run/source/artifact and exact case identity; a failed overall run may supply
  its independently completed passed cases, never an overall success claim.
- Complete comparison from that case's own evidence SHA through target SHA;
  unchanged test/assertion/helper/fixture semantics and complete relevant execution
  dependency closure, generated resources, actual native binaries and Host code.
- Matching actual compiler/SDK, configuration, simulator model/OS build/architecture
  and relevant runtime inputs. Missing or ambiguous identity invalidates reuse.
  Random IDs/unique workspaces are generated by the unchanged fixtures and are
  not replaced by fixed values. Their identity/digest assertions are preserved.
- No newer affected failure, mandatory fresh requirement or unverified/stale
  registry input. Live PyPI/network installation acceptance is rerun when fresh
  network/registry behavior is required; it cannot be inferred from a source hash.
