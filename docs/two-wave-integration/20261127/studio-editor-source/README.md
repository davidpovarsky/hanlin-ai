## Boundaries

The observer writes only the existing XCTest exchange replies and external evidence. Every successful phase rereads actual app/data/group/configuration roots. The final phase repeats complete shipped SDK/compiler/template validation and requires actual source preservation and actual restarted process evidence.

The separate input producer accepts one exact Expo source-import request. It independently resolves current MiniApps roots and SDK, copies only the original selected template into a fresh `Documents/HanlinStudioImport-<runID>/expo-hello-world` folder, uses exclusive regular-file writes, and atomically publishes `STAGED_INPUTS_ONLY` outside production containers. It never creates a Studio project, journal, preference, log, grant, queue record or acceptance result.

Window rectangles correlate observed left/right editors; they are not claimed to be persistent scene identifiers. AX snapshot address strings are rejected. Independent stale editor text and the real journal's original bytes establish the separate writer. No second filesystem writer, private scene activation or injected conflict is used.

The preserved original XCTest timestamp helper records whole seconds. R2 therefore permits equal observation times for the next strictly ordered phase, while rejecting backward time and skipped phases. The same-second positive and backward-time negative are included in the final controls. The original checkpoint helper remains byte-preserved.
