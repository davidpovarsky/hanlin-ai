# Local media in canonical history

Historical model-part registration explicitly creates a `.history` presentation. A sealed
history session permits only the catalog's local media subtree to inherit the host enablement
captured above the Surface's history disable. The full Surface remains disabled for forms.
An ordinary sealed live session gains no permission; closed/disposed sessions lose it.
The Session event relay and original owner relay remain revoked, with no outbound listener,
native admission, Session creation or continuation added by media interaction.

Only the existing Image/Video/Audio/YouTube catalog builders receive this scope. Actual parent
disable is captured before applying history disable, and the media boundary additionally checks
the real scene phase. Players require an explicit request and unload when disabled, backgrounded,
hidden or disposed. URL/video/poster identity changes reset the request before construction.
Native Video/Audio retain their official builders and add an admitted HTTPS source Link. YouTube
retains the sanctioned IFrame document and canonical source. No autoplay or model HTML/JS added.

## Component UI acceptance contract v1

The seven named UI obligations may aggregate authentic per-case passes at the target source
only when each pass's exact identity, assertion semantics, full source/transitive closure,
fixtures, launch/runtime inputs, official/transitive pins, toolchain, simulator OS/environment
and required freshness are demonstrably unchanged from its OWN original evidence SHA. An
uncertain or changed case is rerun. Missing, failed, skipped and not-executed cases never qualify.
Keep EXECUTED_PASS, REUSED_VERIFIED_PASS, FAILED, NOT_RUN and BLOCKED separate per identity.
Aggregate component acceptance is not a new seven-case execution or original app acceptance.

For an affected-case retry, the manual selector accepts `exact_test_selector` containing only
whitelisted method names (optionally full `MediaReplayUITests/MediaReplayUITests/` prefix),
comma/whitespace separated. An empty selector executes all seven. Requested identities and the
actual unique Passed nodes must match exactly; unknown/duplicate/missing selections fail.
