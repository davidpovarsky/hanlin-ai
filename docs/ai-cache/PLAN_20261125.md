## Source ownership and synchronization

- provider_cache: HanlinChatCore policy/config/Factory/Engine/RequestBuilder/Parser; original Swift AI SDK serializer changes
- native_bridge: APIManager prompts/scopes/usage mapping; HanlinAgentSession; active Expo/NativeScript assistant Host service and declarations
- cache_observability: AutomaticWebSearchCoordinator; AgentDiagnostics; OpenTelemetry adapter; dependency ADR
- root: Google explicit resource lifecycle; manifest/dependency/lock updates; integration; all Native validation; Asana; publication

Each lane commits its own changes in its isolated worktree. The integrator rereads published and relevant local heads at phase boundaries, compares semantic/source impact, merges compatible completed commits, and records any work still owned elsewhere. Never force-push or overwrite another worktree. Only root dispatches Apple builds/tests. New tests cover meaningful behavior: provider wire options and usage semantics, prefix stability, cancellation/isolation, cache expiry/coalescing, bridge reachability and reference lifecycle.

## Dependency decisions being implemented

Use the original maintained Swift AI SDK and existing MCP Swift SDK. Replace local hand-maintained LRU eviction with the original LRUCache product while retaining Hanlin-specific TTL/coalescing and cancellation. Bridge SDK telemetry to the original OpenTelemetry API/SDK, with prompt/input/output recording off and exporter configuration explicit. No second JS model engine, duplicate persistence database, or unused server cache/gateway is installed. Full decision matrix and source references are recorded by C1.

## Acceptance and rollback

Keep EXECUTED_PASS, REUSED_VERIFIED_PASS, FAILED, NOT_RUN and BLOCKED distinct. Freeze and hash source/test/dependency inputs for each native run. Cache statistics are observed token accounting, not invented monetary savings. Explicit resource creation may incur provider storage charges and is never an automatic chat side effect. Public policy remains optional for backward-compatible decoding and allows returning to provider defaults. Do not mark a live provider or physical device obligation passed from local stubs. Record blockers with exact cause rather than close the parent.
