# Upstream protection and proof delivery

A separate repository Administration:read credential is confined to exact protection/rules reads. The normal Actions identity retains proof publication and protected merge operations. Both paths omit the other credential where unnecessary.

The producer sends one explicit, attempt-bound consumer dispatch only for the actual GitHub Actions bot. Other authenticated actors retain the original workflow_run path. The consumer requires immutable original producer identity and real completion within90seconds/20reads; it cannot turn failed or pending runs into a passing proof.
