# Departure Budget

An original SDK-only Expo/SwiftUI MiniApp. Adjust target date/time, travel, preparation and early-arrival buffer. Presets update the native steppers. The timeline crosses dates correctly, and a three-item checklist can be toggled or cleared.

Source entry: index.ts. UI: App.tsx. Calculation module: model.ts.

The project tsconfig only selects authored files. Compiler policy and dependency resolution come from the supplied SDK. No extra dependency installation, suppressions or compiler overrides.

Portable validation/build evidence does not establish native launch, installation, layout or interaction success.
