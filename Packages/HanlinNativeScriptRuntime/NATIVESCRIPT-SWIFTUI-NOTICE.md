# NativeScript SwiftUI notice

Hanlin embeds the provider contract derived from `@nativescript/swift-ui`
4.0.2 and bundles that package's official JavaScript implementation into the
prepared acceptance application. The upstream work is Copyright OpenJS
Foundation, Progress Software Corporation, and NativeScript contributors and
is distributed under Apache License 2.0. See
`LICENSE-NATIVESCRIPT-SWIFT-UI`.

Hanlin's extracted provider contract changes visibility and actor annotations
for Swift 6.2 host integration and intentionally omits unrelated plugin source.
The downstream fixture provider is Hanlin-specific.
